# Running-Tracker
### 러닝/걷기/휴식 기록을 관리하는 React 토이 프로젝트
> 프로젝트 기간 : 2025.10.16 ~ 2025.10.22
> 
> URL : https://running-tracker-kappa.vercel.app/

## 🎯 구현 기능
- **CRUD** 기능 (기록 추가·조회·수정·삭제)
- **LocalStorage** 기반 데이터 영구 저장
- 기록을 **날짜, 총 거리, 러닝 거리** 기준으로 정렬
- **반응형** 레이아웃 지원
